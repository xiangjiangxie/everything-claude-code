# /docs

## 用途

查询库、框架或 API 的最新文档，并返回带有相关代码片段的摘要回答。使用 Context7 MCP（resolve-library-id 和 query-docs），因此回答基于当前文档而非训练数据。

## 用法

```
/docs [库名] [问题]
```

多词参数使用引号以便作为单个标记解析。示例：`/docs "Next.js" "如何配置中间件？"`

如果省略库名或问题，则提示用户提供：
1. 库或产品名称（例如 Next.js、Prisma、Supabase）。
2. 具体问题或任务（例如"如何设置中间件？"、"认证方法"）。

## 工作流

1. **解析库 ID** — 调用 Context7 工具 `resolve-library-id`，传入库名和用户问题，获取 Context7 兼容的库 ID（例如 `/vercel/next.js`）。
2. **查询文档** — 调用 `query-docs`，传入该库 ID 和用户问题。
3. **摘要输出** — 返回简洁准确的回答，并包含从获取的文档中提取的相关代码示例。注明库名（以及版本，如相关）。

## 输出

用户将收到基于当前文档的简短准确回答以及有用的代码片段。如果 Context7 不可用，则说明情况并基于训练数据回答，同时注明文档可能已过时。
