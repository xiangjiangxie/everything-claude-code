# 性能优化

## 模型选择策略

**Haiku 4.5**（Sonnet 90% 的能力，成本节省 3 倍）：
- 频繁调用的轻量级 agent
- 结对编程和代码生成
- 多 agent 系统中的 worker agent

**Sonnet 4.6**（最佳编码模型）：
- 主要开发工作
- 编排多 agent 工作流
- 复杂编码任务

**Opus 4.5**（最深度推理）：
- 复杂架构决策
- 需要最强推理能力的场景
- 研究和分析任务

## 上下文窗口管理

以下场景避免使用上下文窗口的最后 20%：
- 大规模重构
- 跨多文件的功能实现
- 复杂交互的调试

上下文敏感度较低的任务：
- 单文件编辑
- 独立工具函数创建
- 文档更新
- 简单 Bug 修复

## 深度思考 + Plan 模式

深度思考默认启用，最多保留 31,999 个 token 用于内部推理。

通过以下方式控制深度思考：
- **切换**：Option+T (macOS) / Alt+T (Windows/Linux)
- **配置**：在 `~/.claude/settings.json` 中设置 `alwaysThinkingEnabled`
- **预算上限**：`export MAX_THINKING_TOKENS=10000`
- **详细模式**：Ctrl+O 查看思考输出

需要深度推理的复杂任务：
1. 确保深度思考已启用（默认开启）
2. 启用 **Plan 模式** 进行结构化方法
3. 使用多轮批判进行深入分析
4. 使用分角色子 agent 获取多元视角

## 构建问题排查

构建失败时：
1. 使用 **build-error-resolver** agent
2. 分析错误信息
3. 增量修复
4. 每次修复后验证
