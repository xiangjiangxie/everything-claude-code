# PHP 模式

> 本文件以 PHP 特定内容扩展通用模式规则。

## 精简控制器，显式服务

- 控制器聚焦于传输层：认证、验证、序列化、状态码。
- 将业务规则移入应用/领域服务中，使其无需 HTTP 引导即可轻松测试。

## DTO 和值对象

- 用 DTO 替代形状繁杂的关联数组，用于请求、命令和外部 API 载荷。
- 对金额、标识符和受约束概念使用值对象。

## 依赖注入

- 依赖接口或窄服务契约，而非框架全局变量。
- 通过构造函数传递协作者，使服务无需服务定位器查找即可测试。
