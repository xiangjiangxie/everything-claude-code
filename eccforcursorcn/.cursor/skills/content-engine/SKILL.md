# 内容引擎

将一个想法转化为强有力的平台原生内容，而非在所有平台发布相同内容。

## 何时激活

- 撰写 X 帖子或推文线程
- 起草 LinkedIn 帖子或发布更新
- 编写短视频脚本或 YouTube 讲解视频脚本
- 将文章、播客、演示或文档复用为社交内容
- 围绕产品发布、里程碑或主题构建轻量级内容计划

## 首要问题

明确以下内容：
- 源素材：我们从什么内容进行适配
- 受众：开发者、投资人、客户、运营者还是普通大众
- 平台：X、LinkedIn、TikTok、YouTube、新闻通讯或多平台
- 目标：品牌认知、转化、招聘、权威建设、发布支持还是互动

## 核心规则

1. 为平台适配内容。不要跨平台发布相同文案。
2. 开头比摘要更重要。
3. 每条帖子应承载一个清晰的核心观点。
4. 使用具体事实，而非口号。
5. 保持行动号召简洁明确。

## 平台指导

### X
- 快速开场
- 每条帖子或线程中的每条推文只传达一个观点
- 除非必要，不要在正文中放链接
- 避免滥用标签

### LinkedIn
- 强有力的首行
- 短段落
- 围绕经验教训、成果和要点进行更明确的表述

### TikTok / 短视频
- 前 3 秒必须抓住注意力
- 围绕视觉效果编写脚本，而非仅靠旁白
- 一个演示、一个主张、一个行动号召

### YouTube
- 尽早展示结果
- 按章节组织结构
- 每 20-30 秒刷新一次画面

### 新闻通讯
- 提供一个清晰的视角，而非一堆不相关的内容
- 部分标题要便于快速浏览
- 让开篇段落承担实际工作

## 复用流程

默认级联：
1. 核心素材：文章、视频、演示、备忘录或发布文档
2. 提取 3-7 个原子化观点
3. 编写平台原生版本
4. 删减跨输出的重复内容
5. 将行动号召与平台意图对齐

## 交付物

当被要求制作一个活动方案时，返回：
- 核心切入角度
- 各平台特定的草稿
- 可选的发布顺序
- 可选的行动号召变体
- 发布前所需的任何缺失信息

## 质量关卡

交付前：
- 每份草稿在其对应平台上阅读起来自然
- 开头有力且具体
- 没有通用的夸张语言
- 除非要求，否则跨平台不重复文案
- 行动号召与内容和受众匹配
