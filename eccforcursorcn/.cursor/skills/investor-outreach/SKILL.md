# 投资人外联

撰写简短、个性化且便于采取行动的投资人沟通内容。

## 何时激活

- 给投资人写冷邮件
- 起草暖引荐请求
- 在会议后或无回复后发送跟进邮件
- 在融资过程中撰写投资人进展更新
- 根据基金投资主题或合伙人匹配度定制外联内容

## 核心规则

1. 每封外联邮件都要个性化。
2. 保持请求低门槛。
3. 用证据说话，而非形容词。
4. 保持简洁。
5. 永远不要发送可以发给任何投资人的通用文案。

## 冷邮件结构

1. 主题行：简短且具体
2. 开头：为什么联系这位特定的投资人
3. 推介：公司做什么、为什么是现在、什么证据最重要
4. 请求：一个具体的下一步
5. 结尾：姓名、职位、需要时附一个信誉锚点

## 个性化来源

引用以下一项或多项：
- 相关的被投公司
- 公开的投资论文、演讲、帖子或文章
- 共同认识的人
- 与投资人关注方向明确匹配的市场或产品

如果缺少这些上下文，请索取或说明该草稿是待个性化的模板。

## 跟进节奏

默认：
- 第 0 天：初始外联
- 第 4-5 天：简短跟进，附一个新的数据点
- 第 10-12 天：最终跟进，干净利落地收尾

除非用户需要更长的序列，否则不要在此之后继续催促。

## 暖引荐请求

为介绍人降低难度：
- 解释为什么这次介绍是合适的
- 附一段可转发的简介
- 可转发的简介控制在 100 字以内

## 会后更新

包含：
- 讨论的具体事项
- 承诺的答复或更新
- 如有可用，附一个新的证据点
- 下一步

## 质量关卡

交付前：
- 邮件已个性化
- 请求明确
- 没有空话或恳求性语言
- 证据点具体
- 字数控制紧凑
