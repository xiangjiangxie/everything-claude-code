# 检查点命令

保存当前验证状态并创建进度检查点：$ARGUMENTS

## 你的任务

创建当前进度的快照，包括：

1. **测试状态** - 哪些测试通过/失败
2. **覆盖率** - 当前覆盖率指标
3. **构建状态** - 构建成功或出错
4. **代码变更** - 修改摘要
5. **后续步骤** - 剩余待完成的工作

## 检查点格式

### 检查点：[时间戳]

**测试**
- 总计：X
- 通过：Y
- 失败：Z
- 覆盖率：XX%

**构建**
- 状态：✅ 通过 / ❌ 失败
- 错误：[如有]

**自上次检查点以来的变更**
```
git diff --stat [last-checkpoint-commit]
```

**已完成任务**
- [x] 任务 1
- [x] 任务 2
- [ ] 任务 3（进行中）

**阻塞问题**
- [问题描述]

**后续步骤**
1. 步骤 1
2. 步骤 2

## 与验证循环配合使用

检查点与验证循环集成：

```
/plan → 实现 → /checkpoint → /verify → /checkpoint → 实现 → ...
```

使用检查点来：
- 在风险变更前保存状态
- 跟踪各阶段的进度
- 在需要时启用回滚
- 记录验证点

---

**提示**：在自然断点处创建检查点：每个阶段之后、重大重构之前、修复关键 bug 之后。
