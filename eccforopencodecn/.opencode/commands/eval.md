# 评估命令

根据验收标准评估实现：$ARGUMENTS

## 你的任务

运行结构化评估以验证实现是否满足要求。

## 评估框架

### 评分类型

1. **二元评分** - 通过/失败
   - 是否可用？是/否
   - 适用于：功能完成度、bug 修复

2. **标量评分** - 0-100 分
   - 效果如何？
   - 适用于：性能、质量指标

3. **量规评分** - 分类评分
   - 多维度评估
   - 适用于：综合审查

## 评估流程

### 步骤 1：定义标准

```
验收标准：
1. [标准 1] - [权重]
2. [标准 2] - [权重]
3. [标准 3] - [权重]
```

### 步骤 2：运行测试

针对每个标准：
- 执行相关测试
- 收集证据
- 评分

### 步骤 3：计算分数

```
最终得分 = Σ (标准分数 × 权重) / 总权重
```
