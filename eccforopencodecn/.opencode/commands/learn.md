# 学习命令

从当前会话中提取模式、经验和可复用的洞察：$ARGUMENTS

## 你的任务

分析对话和代码变更以提取：

1. **发现的模式** - 重复出现的解决方案或方法
2. **应用的最佳实践** - 效果良好的技术
3. **应避免的错误** - 遇到的问题及解决方案
4. **可复用的代码片段** - 值得保存的代码模式

## 输出格式

### 发现的模式

**模式：[名称]**
- 上下文：何时使用此模式
- 实现：如何应用
- 示例：代码片段

### 应用的最佳实践

1. [实践名称]
   - 为什么有效
   - 何时应用

### 应避免的错误

1. [错误描述]
   - 出了什么问题
   - 如何预防

### 建议的技能更新

如果模式具有重要意义，建议更新：
- `skills/coding-standards/SKILL.md`
- `skills/[domain]/SKILL.md`
- `rules/[category].md`

## 直觉规则格式（用于 continuous-learning-v2）

```json
{
  "trigger": "[触发此学习的情境]",
  "action": "[应采取的操作]",
  "confidence": 0.7,
  "source": "session-extraction",
  "timestamp": "[ISO 时间戳]"
}
```
