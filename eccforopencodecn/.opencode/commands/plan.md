# 计划命令

为以下内容创建详细的实现计划：$ARGUMENTS

## 你的任务

1. **重述需求** - 明确需要构建的内容
2. **识别风险** - 发现潜在问题、阻塞点和依赖关系
3. **创建分步计划** - 将实现分解为多个阶段
4. **等待确认** - 必须收到用户批准后才能继续

## 输出格式

### 需求重述
[清晰、简洁地重述将要构建的内容]

### 实现阶段
[阶段 1：描述]
- 步骤 1.1
- 步骤 1.2
...

[阶段 2：描述]
- 步骤 2.1
- 步骤 2.2
...

### 依赖关系
[列出外部依赖、API、所需服务]

### 风险
- 高：[可能阻塞实现的关键风险]
- 中：[需要关注的中等风险]
- 低：[次要关注点]

### 预估复杂度
[高/中/低，附带时间估算]

**等待确认**：是否按此计划执行？（是/否/修改）

---

**关键**：在用户明确以"是"、"继续"或类似肯定回复确认之前，不要编写任何代码。
