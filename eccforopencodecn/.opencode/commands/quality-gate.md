# 质量门控命令

按需为文件或项目范围运行 ECC 质量流水线。

## 用法

`/quality-gate [path|.] [--fix] [--strict]`

- 默认目标：当前目录（`.`）
- `--fix`：允许在已配置的地方自动格式化/修复
- `--strict`：在支持的地方将警告视为失败

## 流水线

1. 检测目标的语言/工具链。
2. 运行格式化检查。
3. 在可用时运行 lint/类型检查。
4. 生成简洁的修复清单。

## 说明

此命令与钩子行为相同，但由操作者手动调用。

## 参数

$ARGUMENTS：
- `[path|.]` 可选目标路径
- `--fix` 可选
- `--strict` 可选
