# 安全审查命令

进行全面的安全审查：$ARGUMENTS

## 你的任务

按照 OWASP 指南和安全最佳实践分析指定代码的安全漏洞。

## 安全清单

### OWASP Top 10

1. **注入攻击**（SQL、NoSQL、操作系统命令、LDAP）
   - 检查参数化查询
   - 验证输入清理
   - 审查动态查询构建

2. **身份验证失效**
   - 密码存储（bcrypt、argon2）
   - 会话管理
   - 多因素认证
   - 密码重置流程

3. **敏感数据泄露**
   - 静态和传输中的加密
   - 正确的密钥管理
   - PII 数据处理

4. **XML 外部实体（XXE）**
   - 禁用 DTD 处理
   - XML 输入验证

5. **访问控制失效**
   - 每个端点的授权检查
   - 基于角色的访问控制
   - 资源所有权验证

6. **安全配置错误**
   - 已移除默认凭证
   - 错误处理不泄露信息
   - 已配置安全头
   - 生产环境禁用调试模式

7. **跨站脚本（XSS）**
   - 输出编码
   - 内容安全策略
   - 输入清理

8. **不安全的反序列化**
   - 验证序列化数据
   - 实现完整性检查

9. **使用含已知漏洞的组件**
   - 运行 `npm audit`
   - 检查过时的依赖

10. **日志和监控不足**
    - 记录安全事件
    - 日志中不包含敏感数据
    - 已配置告警

### 额外检查

- [ ] 代码中的密钥（API 密钥、密码）
- [ ] 环境变量处理
- [ ] CORS 配置
- [ ] 速率限制
- [ ] CSRF 防护
- [ ] 安全 Cookie 标志
