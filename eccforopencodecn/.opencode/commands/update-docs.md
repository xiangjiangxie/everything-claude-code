# 更新文档命令

更新文档以反映最近的变更：$ARGUMENTS

## 你的任务

1. **识别变更的代码** - `git diff --name-only`
2. **查找相关文档** - README、API 文档、指南
3. **更新文档** - 保持与代码同步
4. **验证准确性** - 文档与实现一致

## 文档类型

### README.md
- 安装说明
- 快速入门指南
- 功能概览
- 配置选项

### API 文档
- 接口描述
- 请求/响应格式
- 身份验证详情
- 错误码

### 代码注释
- 公共 API 的 JSDoc
- 复杂逻辑说明
- TODO/FIXME 清理

### 指南
- 操作教程
- 架构决策记录（ADR）
- 故障排除指南

## 更新清单

- [ ] README 反映当前功能
- [ ] API 文档与接口匹配
- [ ] 变更函数的 JSDoc 已更新
- [ ] 示例可正常运行
- [ ] 链接有效
- [ ] 版本号已更新

## 文档质量

### 好的文档
- 准确且最新
- 清晰简洁
- 包含可运行的示例
- 覆盖边界情况

### 避免
- 过时的信息
- 缺失的参数
- 损坏的示例
- 模糊的表述

---

**重要**：文档应与代码变更同步更新，而非事后补充。
