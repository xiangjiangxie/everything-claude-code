# /docs

## 目的

查找库、框架或 API 的最新文档，并返回包含相关代码片段的总结答案。使用 Context7 MCP（resolve-library-id 和 query-docs），因此答案反映的是当前文档，而非训练数据。

## 用法

```
/docs [库名] [问题]
```

对多词参数使用引号，以便将其解析为单个标记。示例：`/docs "Next.js" "如何配置中间件？"`

如果省略了库名或问题，提示用户提供：
1. 库或产品名称（例如 Next.js、Prisma、Supabase）。
2. 具体的问题或任务（例如"如何设置中间件？"、"认证方法"）。

## 工作流

1. **解析库 ID** — 使用库名和用户的问题调用 Context7 工具 `resolve-library-id`，获取 Context7 兼容的库 ID（例如 `/vercel/next.js`）。
2. **查询文档** — 使用该库 ID 和用户的问题调用 `query-docs`。
3. **总结** — 返回简洁、准确的答案，并包含从获取的文档中提取的相关代码示例。提及库名（以及版本，如相关）。

## 输出

用户收到由当前文档支持的简短、准确的答案，以及任何有帮助的代码片段。如果 Context7 不可用，说明情况并从训练数据中回答，附加注明文档可能已过期。
