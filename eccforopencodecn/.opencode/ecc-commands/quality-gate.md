# 质量门禁命令

按需对文件或项目范围运行 ECC 质量流水线。

## 用法

`/quality-gate [path|.] [--fix] [--strict]`

- 默认目标：当前目录（`.`）
- `--fix`：在已配置的情况下允许自动格式化/修复
- `--strict`：在支持的情况下将警告视为失败

## 流水线

1. 检测目标的语言/工具链。
2. 运行格式化检查。
3. 如可用则运行代码检查/类型检查。
4. 生成简洁的修复列表。

## 注意事项

此命令镜像 hook 行为，但由操作者手动调用。

## 参数

$ARGUMENTS:
- `[path|.]` 可选目标路径
- `--fix` 可选
- `--strict` 可选
