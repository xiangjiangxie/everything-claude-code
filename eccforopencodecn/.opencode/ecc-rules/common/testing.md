# 测试要求

## 最低测试覆盖率：80%

测试类型（全部必需）：
1. **单元测试** - 独立的函数、工具、组件
2. **集成测试** - API 端点、数据库操作
3. **E2E 测试** - 关键用户流程（框架按语言选择）

## 测试驱动开发

强制工作流程：
1. 先编写测试（RED）
2. 运行测试 - 应该失败
3. 编写最小化实现（GREEN）
4. 运行测试 - 应该通过
5. 重构（IMPROVE）
6. 验证覆盖率（80%+）

## 测试失败排查

1. 使用 **tdd-guide** 代理
2. 检查测试隔离性
3. 验证 mock 是否正确
4. 修复实现而非测试（除非测试本身有误）

## 代理支持

- **tdd-guide** - 在新功能开发时主动使用，强制先写测试
