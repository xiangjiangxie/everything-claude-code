# PHP 编码风格

> 本文件以 PHP 特定内容扩展了 [common/coding-style.md](../common/coding-style.md)。

## 标准

- 遵循 **PSR-12** 格式化和命名约定。
- 应用代码中优先使用 `declare(strict_types=1);`。
- 在新代码允许的范围内，所有地方使用标量类型提示、返回类型和类型化属性。

## 不可变性

- 跨服务边界的数据优先使用不可变 DTO 和值对象。
- 请求/响应负载尽可能使用 `readonly` 属性或不可变构造函数。
- 简单映射使用数组；将业务关键的结构提升为显式类。

## 格式化

- 使用 **PHP-CS-Fixer** 或 **Laravel Pint** 进行格式化。
- 使用 **PHPStan** 或 **Psalm** 进行静态分析。
- 将 Composer 脚本检入版本控制，确保本地和 CI 运行相同的命令。

## 导入

- 为所有引用的类、接口和 trait 添加 `use` 语句。
- 除非项目明确偏好完全限定名，否则避免依赖全局命名空间。

## 错误处理

- 对异常状态抛出异常；新代码中避免将 `false`/`null` 作为隐藏的错误通道返回。
- 在请求输入到达领域逻辑之前，将其转换为已验证的 DTO。
