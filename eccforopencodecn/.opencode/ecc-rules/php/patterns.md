# PHP 模式

> 本文件以 PHP 特定内容扩展了 [common/patterns.md](../common/patterns.md)。

## 瘦控制器，显式服务

- 控制器聚焦于传输：认证、验证、序列化、状态码。
- 将业务规则移到应用/领域服务中，便于无需 HTTP 引导即可测试。

## DTO 和值对象

- 用 DTO 替换形状复杂的关联数组，用于请求、命令和外部 API 负载。
- 对金额、标识符、日期范围和其他受约束的概念使用值对象。

## 依赖注入

- 依赖接口或窄服务契约，而非框架全局变量。
- 通过构造函数传递协作者，使服务无需服务定位器查找即可测试。

## 边界

- 当模型层的职责超出持久化时，将 ORM 模型与领域决策隔离。
- 将第三方 SDK 封装在小的适配器后面，使代码库其余部分依赖你的契约而非第三方的。
